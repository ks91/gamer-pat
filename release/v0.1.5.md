# GAMER PAT Prompt-Agent v0.1.5

## Summary
- Updates the GAMER PAT instruction baseline to `1.1`.
- Adds CLI/loglm-only guidance for using repository helper scripts.
- Updates prompt-agent package version metadata to `0.1.5`.

## Included in This Release
- Changed the Writing Mode LaTeX preamble from `here` to `float`, reflecting the more appropriate package for `[H]` float placement.
- Updated duplicated Writing Mode content in the loglm install package.
- Added CLI/loglm guidance to check `scripts/` and `scripts/README.md` before manually processing files.
- Instructed CLI/loglm GAMER PAT installations to use `scripts/extract_pdf_annotations.py` for commented or annotated PDF review workflows.
- Added Poppler `pdftotext` as a requirement for PDF annotation extraction workflows.
- Updated README metadata to prompt-agent package version `0.1.5` and instruction baseline `1.1`.
